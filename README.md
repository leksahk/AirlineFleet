# ✈️ Airline Fleet Manager

## 📖 Про проєкт
Цей веб-додаток розроблено для управління авіапарком авіакомпанії. Програма дозволяє ефективно керувати флотом, додавати різні типи літаків (пасажирські, вантажні, військові та приватні джети), редагувати їхні характеристики, видаляти, а також виконувати пошук та сортування за заданими параметрами.

## ⚙️ Технологічний стек
* **Мова програмування:** Java
* **Фреймворк:** Spring Boot (Spring Web, Spring MVC)
* **View Layer (Шаблонізатор):** Thymeleaf
* **Стилізація (CSS):** Bootstrap 5
* **Тестування:** JUnit 5, Mockito, Spring Boot Test
* **Аналіз якості коду:** JaCoCo (Code Coverage > 90%)

## 🚀 Основний функціонал
* **Керування флотом (CRUD):** Створення, читання, оновлення та видалення літаків різних типів.
* **Бізнес-логіка та розрахунки:** Автоматичний підрахунок загальної пасажирської та вантажної місткості всього доступного авіапарку.
* **Пошук:** Фільтрація літаків за діапазоном споживання пального.
* **Сортування:** Можливість сортування флоту за дальністю польоту, максимальною швидкістю або споживанням пального (за зростанням та спаданням).
* **Кастомна обробка помилок:** Налаштована власна сторінка (Whitelabel Error Page) для обробки стандартних HTTP-помилок.
